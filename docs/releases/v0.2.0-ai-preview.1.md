# WonderBox AI Preview v0.2.0-ai-preview.1

这是 [jasonwong1991/WonderBox](https://github.com/jasonwong1991/WonderBox) 的实验性 fork，独立发布，保留原作者的 MIT 许可。应用包内含完整许可文件。本版本标记为 Pre-release，供体验和反馈。

## 新增能力

- 在清理明细中点击「AI 分析」，先查看目录摘要，再了解实际删除范围、删除后果、恢复方式和网页来源。
- 首轮分析后可连续追问，原报告和此前问答保留在同一窗口；支持取消、手动重试，关闭窗口即清空记录。
- 「设置 → 清理 AI 分析」可调整 Codex 路径、模型和思考强度，默认 `gpt-6.1-sol / medium`；更改设置影响下一次请求。

AI 分析不改变勾选，也不执行清理。原有清理功能仍需用户自行操作。

## 下载与使用

下载 `WonderBox-AI-Preview-0.2.0-ai-preview.1-arm64.zip`，核对同页 `SHA256SUMS.txt`，解压后将 `WonderBox-AI-Preview.app` 放入「应用程序」。

发行包仅支持 Apple Silicon，系统要求 macOS 14+；本次在 macOS 26.6.2 上验证，未验证 Intel。应用使用独立 Bundle ID `com.wondercraft.WonderBox.AIPreview`，可与原版并存。

AI 功能需要本机自行安装并登录 Codex CLI。本次使用 0.159.2 验证；发行包不包含 Codex、API Key 或登录凭据。默认自动查找 CLI，也可在设置中手动指定路径。可用模型取决于你的 Codex 账号。

本包使用 ad hoc 签名，未经 Apple 公证；首次打开可能被 Gatekeeper 拦截。核对来源和校验值后，可使用 macOS「系统设置 → 隐私与安全性」提供的单个应用授权流程。

## 数据说明

发送前可预览匿名化路径、大小、最多两层目录结构及删除方式。不会自动读取文件内容，不跟随符号链接；目录名称仍可能包含个人信息。目录摘要、问题和历史回答会交给本机 Codex，由其连接 Codex 服务并搜索网页，可能消耗订阅额度。WonderBox 只在当前窗口内存中保存分析和问答。

## 验证结果

- 原生 XCTest：44 项通过，0 失败。
- 原生界面：16 个场景通过，包含连续追问、失败、取消、180 秒超时、重试与关闭清空。
- 真实联网：Codex 0.159.2 使用 `gpt-6.1-sol / high` 完成 JetBrains 首轮分析及两轮追问，返回官方来源；未执行清理。
- Debug 与 Release 构建、预览版签名检查通过。更多功能说明见 [清理分析文档](../cleanup-analysis.md)。
- 发行包解压后再次通过签名检查；主程序与两个 helper 均为 arm64，包内 MIT 许可与仓库原文一致。
